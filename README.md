# 我的地点地图 MVP

这个版本只聚焦两件事：

1. 从高德 POI 搜索结果中选择地点，或双击地图手动标点。
2. 为每个地点设置自定义分类和自定义图标，并在地图上视觉化。

## 第一次运行

1. 注册并登录高德开放平台。
2. 创建应用。
3. 添加 Key，服务平台选择“Web端（JS API）”。
4. 获取 `Key` 和 `安全密钥 securityJsCode`。
5. 打开 `config.js`，替换其中两项。
6. 不要直接双击 `index.html`。请通过本地 HTTP 服务打开。

Mac 可在项目文件夹中打开“终端”，运行：

```bash
python3 -m http.server 8000
```

然后浏览器访问：

```text
http://localhost:8000
```

## 当前功能

- 高德中国大陆地图底图
- 高德 POI 关键词搜索
- 从搜索结果添加地点
- 双击地图手动标点
- 自定义分类名称
- 7 个内置 SVG 图标
- 上传 PNG / JPG / WebP / SVG 作为自己的图标
- 地图 Marker 可视化
- 分类筛选
- 编辑、删除地点
- JSON 导入和导出
- 数据保存在浏览器 `localStorage`

## 数据说明

地图上的地点事实信息（搜索结果、坐标、地址）来自高德 POI。
你自己的分类、图标和备注保存在当前浏览器。

浏览器缓存被清除时，本地数据可能丢失。请定期使用“导出”按钮备份。
